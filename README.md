# sirca.pro

Официальный дилер **Sirca** и **G Nature**. Статический сайт на Astro: витрина с ценами, задачи, калькулятор расхода, реквизиты ООО «А.С. КОЛОР».

## Запуск

```bash
npm install
npm run dev
```

Сборка для Cloudflare Pages: `npm run build` → каталог `dist/`. Команда сборки: `npm run build`, выход: `dist`.

## Правила витрины

- Цены на карточках обязательны. Ориентир: G Nature — gnature.ru, Sirca — woodperfect.ru, наша цена ≈ −10%, округление до 10 ₽.
- В футере каждой страницы: сайт не является публичной офертой (ст. 437 ГК РФ).
- Адрес склада не публикуем. Доставка: Москва и вся Россия.
- Бренды не смешиваем в одном каталоге: `/gnature` и `/sirca`, карточки `/product/{brand}/{sku}`.
