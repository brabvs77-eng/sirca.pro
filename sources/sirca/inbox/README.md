# Sirca — входящие файлы для анализа

Сюда кладите **временные** материалы, которые агент должен разобрать перед переносом на сайт.

## Что сюда

- PDF / Word / Excel с каталогом, прайсом, TDS
- таблицы SKU, расходов, отвердителей
- черновики текстов для глав `/sirca/*` и `/knowledge/*`
- сырые фото и сканы (до обработки)

## Что не сюда

| Тип | Куда после обработки |
|---|---|
| Данные товаров | `src/data/products-sirca.ts` |
| Картинки на витрину | `public/img/sirca/` |
| Обложка каталога | `public/img/covers/sirca.webp` |
| Статьи и спецификации (итог) | `docs/sirca-*.md` |
| Страницы сайта | `src/pages/sirca/` |

## Именование

`{тип}-{тема}-{дата}.{расширение}`

Примеры:

- `catalog-domostroenie-2026-09.pdf`
- `prices-woodperfect-2026-09.xlsx`
- `chapter-parquet-draft.md`

Файлы из `inbox/` не попадают на сайт автоматически — только после явной обработки.
