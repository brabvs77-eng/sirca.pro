# G Nature — входящие файлы для анализа

Сюда кладите **временные** материалы перед переносом на сайт.

## Что сюда

- PDF / Word / Excel с каталогом, прайсом, TDS
- черновики текстов для `/gnature/*` и `/knowledge/*`
- сырые фото и сканы (до обработки)

## Что не сюда

| Тип | Куда после обработки |
|---|---|
| Данные товаров | `src/data/products-gnature.ts` |
| Картинки на витрину | `public/img/products/` |
| Обложка каталога | `public/img/covers/gn.webp` |
| Статьи и спецификации (итог) | `docs/gnature-*.md` |
| Страницы сайта | `src/pages/gnature/` |

Файлы из `inbox/` не попадают на сайт автоматически — только после явной обработки.
