# Конкурентный анализ: продажа краски Sirca в России

Дата обзора: сентябрь 2026. Источники — публичные сайты дилеров и дистрибьюторов. Частоты запросов в Wordstat не снимались (нужна авторизация Яндекса); приоритет семантики — качественный, по выдаче и структуре чужих каталогов.

Целевая аудитория рынка: мебельные производства, столярки, изготовители дверей/окон/лестниц, паркетчики, малярные цеха, реже — частные мастера и дизайнеры.

## 1. lakpro.ru — Арикон ЛК системы

Главный игрок. Склад 10 000 м² / 700+ тонн, колеровочная лаборатория (DataColor, Corob, гиромиксеры), технологи выезжают на производства, своё производство отвердителей Neomix и растворителей. Представительства в Москве, Воронеже, Краснодаре, Ростове, Ульяновске.

**Сильные стороны**

- Статус эксклюзивного дистрибьютора и узнаваемый B2B-бренд.
- Каталог разложен по химии и среде: ПУ / акрил / ПЭ / водные / НЦ / УФ / масла / морилки / патины / спецэффекты / металл и пластик / экстерьер.
- Техническая экспертиза как продукт: циклы отделки, подбор под эталон, обучение персонала.
- Контент-маркетинг: выставки «Мебель», UMIDS, новинки Tintorama, Zerogloss, Polibian130.
- Широкая дилерская сеть и логистика по РФ.
- SEO-тексты на категориях («купить ЛКМ Сирка», «краска Сирка»).

**Слабые стороны**

- Цены почти нигде не открыты. Заказ = заявка / звонок.
- Сайт корпоративный, не магазин: нет корзины, фасовок, наличия в реальном времени.
- Тон «для производств». Частный мастер и небольшой цех теряются.
- SEO-тексты внизу главной размывают тему («фасадные краски», «интернет-магазин») и выглядят шаблонно.
- Нет калькулятора расхода, конфигуратора цикла, онлайн-веера цвета.
- Визуал средний: мало живых выкрасов, кейсов фабрик, видео нанесения.

**Вывод:** сильный офлайн и слабый e-commerce. Для sirca.pro это главный ориентир по ассортименту и сервису, но не по удобству покупки.

## 2. studio-sirca.ru — Studio Sirca (Москва)

Дилер Москвы. Телефон +7 926 717-72-42 совпадает с карточкой «Москва (ИП Иванов О.В.)» на lakpro.ru. Адрес: Нагорный проезд, 7, стр. 5, оф. 304.

**Сильные стороны**

- Гео-SEO: «Москва», «Московская область», «региональный дилер».
- Есть страницы доставки, контактов, части каталога (ColorSirca, домостроение).
- Обещают договоры на поставку, колеровку, расчёт объёма, образцы.

**Слабые стороны**

- Главная написана как статья про «декоративные краски для стен», «фасадные краски», «противогрибковые составы». Это другой рынок и вредит релевантности.
- Цены только по телефону. Корзины нет.
- Дизайн шаблонный, доверие слабое (баннеры «2026», общие формулировки).
- Мало карточек с артикулами, отвердителями, глоссом, TDS.
- Опечатки и канцелярит («Sirca .p.a.»).

**Вывод:** занимает запросы «Sirca Москва», но сайт не продаёт. Легко обойти точными карточками, ценой и нормальным текстом про мебельные ЛКМ.

## 3. mv-color.ru — МВК (Санкт-Петербург)

Самый предметный региональный сайт среди дилеров Sirca.

**Сильные стороны**

- Каталог по системам: водные акриловые, ColorSirca, УФ, НЦ, ПЭ, прозрачные ПУ, экстерьер, спецэффекты, масла.
- Карточки с составом системы: грунт + отвердитель + разбавитель (например FPU49 + CT7 + DPU800).
- Новинки с описанием свойств: OPP530G10, FPP230TIX, OWPI930G30, FWPI130, MICA, «роса», VelTouch, Cemento.
- Офферы: бесплатная доставка по СПб/ЛО от 10 000 ₽, оплата после доставки, колеровка RAL / NCS / Tikkurila, выезд технолога, образцы.
- Заголовок заточен под коммерческий запрос: «Лакокрасочные материалы SIRCA — купить в Санкт-Петербурге».

**Слабые стороны**

- Региональный замок: слабо претендует на федеральную выдачу.
- Цены на витрине не видны.
- Интерфейс устарел, мобильная версия слабая.
- Нет отзывов производств, кейсов, блога.
- Часть URL с опечатками (`prozrachnye-poleuretanovye-sistemy`).

**Вывод:** лучший образец структуры каталога среди дилеров. Имеет смысл повторить логику «система + карточка + колеровка + доставка», но сделать федерально и с ценой.

## 4. sirca-samara.ru — Рост-Поволжье

**Сильные стороны**

- Домен с брендом и гео. На рынке с 2011.
- Явный список линеек и колеровочных систем: ColorSirca, RAL, NCS, Tikkurila, WCP, CS.
- Отдельный акцент на водных материалах для детской мебели.
- Бесплатная доставка по Тольятти и до ТК.

**Слабые стороны**

- Одностраничник / визитка, каталог почти не раскрыт.
- В title смешаны SIRCA, CONFAY, RAKOLL — размывает бренд.
- Формулировка «склад 700 тонн» копирует Арикон, выглядит недостоверно.
- Нет цен, корзины, карточек, TDS, отзывов.

**Вывод:** типичный региональный дилер. Не конкурент по продукту в вебе.

## 5. kraskiklei.ru — Воронеж

**Сильные стороны**

- Редкое для ниши: подробные циклы отделки (патина, декапе, краколет / VES2030) с расходами г/м² и артикулами.
- Хорошо закрывает информационные запросы технологов.
- Есть разделы паркетных лаков и ColorSirca.

**Слабые стороны**

- Страница бренда, не полноценный магазин Sirca.
- Нет цен и оформления заказа.
- Гео узкое. Дизайн старый.

**Вывод:** контент-конкурент. Для sirca.pro такие циклы — готовая модель блога / базы знаний.

## 6. woodperfect.ru — единственный заметный e-shop

**Сильные стороны**

- Открытые цены, фасовки 0,5–1 кг, корзина, артикулы.
- Указаны отвердитель, глосс, расход, способ нанесения.
- Сравнение с аналогами Sayerlack (OPU79 ≈ TZ 70, FPP26 ≈ TU 271/13, OPU57 ≈ TZ 58).
- Фильтры по типу: грунт для МДФ, водные, детская мебель, металл/пластик, морилки.

Примеры цен (витрина, ориентир): OPU79 ~2 449 ₽/кг, LPU002 ~2 950 ₽, FPP26 ~1 295 ₽, FPU15 ~1 340 ₽, OPU57 ~1 579 ₽, OPU60 ~2 639 ₽.

**Слабые стороны**

- Старый движок, слабый UX, ошибки в карточках (у чёрной OPP053 текст про белую эмаль).
- Ассортимент смешан с Sayerlack — бренд Sirca не «свой».
- Нет статуса официального дилера, лаборатории, выезда технолога.
- Мало образовательных материалов и доверия крупному производству.

**Вывод:** единственный, кто закрывает запрос «купить банку сегодня». Это главная дыра рынка и главная возможность sirca.pro.

## 7. sirca.it — производитель

Премиальный бренд-сайт: Interior / Exterior / Plastics / Glass. Линейки Zero Gloss, S-Cover, Provocazioni, Flameshield, 4ALL, Extra Plus (гарантия до 20 лет на водный экстерьер). Экология и R&D.

Российские дилеры почти не переносят эти линейки и визуал. Сайты выглядят как прайс химикатов, не как итальянский бренд.

## Повторяющиеся слабости рынка

1. **Цены скрыты.** Почти все дилеры Sirca пишут «уточняйте по телефону».
2. **Нет нормального интернет-магазина** с наличием, фасовкой и комплектом «эмаль + отвердитель + разбавитель».
3. **Сайты устарели**, плохо выглядят на телефоне.
4. **Тексты либо канцелит, либо SEO-вода** не про мебель, а про «краски для стен».
5. **Мало выкрасов, циклов, видео, отзывов производств.**
6. **Бренд Sirca в вебе размыт:** нет одного сильного национального витринного сайта (производитель на итальянском, Арикон — про компанию, дилеры — про город).
7. **Сравнение с Renner / Sayerlack / ICA** почти нигде не собрано, хотя мастера ищут аналоги по артикулу.

## Окно для sirca.pro

1. Федеральная витрина Sirca с ценой, наличием и фасовкой.
2. Карточки как у МВК/Woodperfect: артикул, глосс, отвердитель, разбавитель, расход, TDS, аналог Sayerlack.
3. Комплекты «цикл под задачу»: кухня МДФ мат, глянец фасад, окно водное, детская мебель, патина, краколет.
4. Онлайн-колеровка: RAL / NCS / ColorSirca / WCP + загрузка эталона.
5. База знаний по циклам (как у kraskiklei) и обучение (как у Renner).
6. Кейсы фабрик и живые выкрасы — этого нет ни у кого из дилеров Sirca на достойном уровне.
7. Не копировать ошибку Studio Sirca: не писать про интерьерные краски для стен.

Позиционирование, которого нет на рынке: *«Официальные материалы Sirca — как в цехе, но купить можно сразу: цена, колеровка, цикл, доставка»*.
