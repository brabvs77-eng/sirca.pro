# План сайта sirca.pro

Официальный дилер **Sirca** и **G Nature**. Один домен, два бренда, общие сервисы. Старт — Cloudflare Pages, затем тот же билд на VPS.

Источники: каталог Sirca «ЛКМ для деревянного домостроения» (54 стр., `sirca.pdf.pdf`), каталог Gnature А5 2026 (`Katalog GN А5_2026_2.pdf`), рекламный каталог GN, `Семантика.docx`, гайды Директ/РСЯ, 279 файлов в корне `main` (карточки, выкрасы, рилсы), плюс разборы конкурентов в `docs/`.

## 2. Позиционирование

**sirca.pro** — официальный дилер двух профессиональных брендов для дерева.

- **G Nature** — натуральные масла и краски: фасад, терраса, дом внутри, баня, пол, столешница. Частник, маляр, застройщик.

Один клиент «крашу дом» должен за 30 секунд попасть в бренд и систему, а не бродить по химии.

УТП (из каталогов и гайдов, без запрещённых «№1»):

- Официальный дилер Sirca и G Nature
- Колеровка RAL / NCS / фирменные веера
- Расчёт системы и литров под породу
- Комплект грунт + финиш + уход
- Консультация технолога
- Доставка по Москве и России (склад на сайте не публикуем)

## 4. Карта контента → страницы

Каждый файл `main` должен появиться на сайте (сжатый, с alt и подписью). Не оставлять «архив в git».

**Карточки GN** `{sku}_{фасовка}.png` + `{sku}_описание.jpg` → галерея товара, schema.org ImageObject.

**Выкрасы** с именем цвета → `/colors/{slug}` и свотчи на 280/425/245/475. slug: `arkticheskij-led`. Alt: «Gnature 280, цвет Арктический лёд».

**Видео** (31):

- продуктовые 110…875 → блок на карточке, poster из png банки, play по тапу;
- «О GNATURE», «Фасад», «Терраса», «Дети 1 июня» → `/gnature` и `/tasks/*`;
- «Вокруг цвета», «просто космос» → цветовые лендинги;
- для РСЯ нарезать 6–15 с, ≤10 МБ (гайд).

**PDF** отдать как `/files/sirca-domostroenie.pdf`, `/files/gnature-catalog-2026.pdf` (сжатые), плюс HTML-версии разделов — поисковик индексирует HTML, не скан.

**Sirca PDF** распилить в MD: породы, УФ, циклы, таблицы параметров (сухой остаток, отвердитель, глосс, г/м²). Таблицы — основа калькулятора Sirca (расход 100–150 г/м² мокрого слоя).

## 6. Калькуляторы

Все считают на клиенте по JSON из каталогов. Без бэкенда на Pages. Результат: литры, число банок по фасовкам, комплект, CTA «заявка на этот расчёт».

### 6.1 Расход (`/calc/raskhod`)

Вход: задача, SKU или «подобрать», площадь м², слои (1/2), порода (коэф. впитывания: строганная 1.0, пилёная 1.25, лиственница 0.95, термо 0.9, ДПК 0.4).  
Формула: `литры = площадь / расход_м2_на_слой * слои * коэф`.  
Выход: литры, банки 0.375 / 0.75 / 2.5 / 10 с округлением вверх и ценой, если цена в прайсе.

Данные: таблица GN выше; Sirca — г/м² мокрого слоя / плотность → литры.

### 6.2 Система под задачу (`/calc/sistema`)

Логика со стр. 26–27 каталога GN + циклы Sirca PDF.

Вход: снаружи/внутри, объект (фасад / терраса / торцы / ДПК / стены / пол / столешница / окна), порода (мягкая / твёрдая / термо / ДПК), эффект (лессир / укрыв / металлик).

Выход: шаги шлифовка → грунт/антисептик → финиш × слои. Пример: ель + фасад + лессир → 870 ×1 + 280 ×2–3. Лиственница + фасад → 875 ×1 + 280 или 425. Окна Sirca → IMW + FWE/FWP + OWE/OWP или ПУ OPP1930G.

### 6.3 Комплект дома (`/calc/komplekt`)

Несколько зон: фасад м², торцы м.п., терраса м², внутри стены, пол. Считает корзину SKU. Главный лид-магнит B2B и «посёлок».

### 6.4 Стоимость м²

`цена_банки / (фасовка_л * расход_м2)` — как gnature.ru «от 300 ₽/м²». Сравнение 1 vs 2 слоя, с грунтом и без.

### 6.5 Паркет / лестница Sirca

Площадь, лак (OW1fG40 / Idrofloor / OPU60G), глосс, отвердитель %. Выход: кг/л лака + отвердитель.

### 6.6 Окна Sirca

Число створок или м² профиля, система водная vs ПУ. Расход из таблиц 100–150 г/м².

### 6.7 Цвет (фаза 2)

Загрузка фото дома (как `repaint.gnature.ru`) или ручной выбор веера «Вокруг цвета» / «Просто космос». На Pages — только палитра + заявка на выкрас. Нейропокраска — отдельный worker или iframe, не блокировать LCP.

### 6.8 Обновление без шлифовки

Возраст покрытия, шелушение да/нет → 110/170 очистка + слой финиша vs полный цикл.

Каждый калькулятор: JSON-LD FAQ, индекс, кнопка «сохранить расчёт» (query string, можно шарить).

## 7. Стек, mobile first, PageSpeed

### Почему не WordPress / Tilda

Конкуренты тяжёлые. Цель: Lighthouse mobile Performance ≥ 90, LCP < 2.5 с, INP < 200 мс, CLS < 0.1. На Pages — только статика.

### Стек волны 1

- **Astro** (HTML по умолчанию, острова только на калькуляторах и меню).
- Контент: Markdown/MDX + `src/data/*.json` (товары, расходы, цвета).
- Стили: один CSS, design tokens, без runtime Tailwind-js. Шрифт: одна гарнитура, cyrillic subset, `font-display: optional`.
- Картинки: при билде Sharp → AVIF/WebP, srcset 320/480/768/1200, `width/height`, lazy кроме LCP-героя.
- Видео: не автоплей, poster, `preload="none"`, на Pages — CF Stream или `<video>` с Range; рилсы в вертикали 9:16 на карточке.
- Формы: `mailto` недопустимо. Cloudflare Pages Function или Worker → Telegram + почта. Файл `functions/api/lead.ts`.
- Аналитика: Метрика partytown/defer, без GTM-простыни на старте.

### Mobile first

- Точка: 360×800. Десктоп — расширение, не основа.
- CTA «расчёт» и «написать» липкие, 44 px.
- Фильтры — bottom sheet, не сайдбар.
- Карточка: фото, цена/«по запросу», расход, 2 кнопки.
- Таблицы Sirca — карточки параметров, не широкая таблица.

### PageSpeed-чеклист релиза

- HTML < 50 КБ first doc, CSS < 20 КБ critical.
- JS first load < 30 КБ (калькулятор только на `/calc/*`).
- Нет каруселей авто, нет шрифтов с Google runtime, нет jQuery.
- `Cache-Control` / `_headers` на Pages: html 300 с, hash-assets immutable.
- Prefetch следующих 2 карточек по viewport.
- Третья сторона: Метрика + мессенджер, больше ничего.

### Cloudflare Pages

```
build: astro build
output: dist/
functions/: api/lead
headers: security + cache
redirects: www → apex
```

Домен sirca.pro → Pages. SSL CF. Preview на `*.pages.dev` для веток.

Переменные: `PUBLIC_PHONE`, `PUBLIC_WHATSAPP`, `PUBLIC_ADDRESS`, `TELEGRAM_TOKEN` (secret).

## 8. Миграция Pages → VPS

Билд не менять. На VPS:

1. Тот же `dist/` за nginx + brotli + http/2 или Caddy.
2. Картинки — локальный `/img` или CF CDN как прокси (оставить CF только как CDN).
3. Functions → маленький Node/Hono на unix socket: лиды, позже наличие/цены из Google Sheet или 1С.
4. DNS: сначала CNAME на Pages, затем A на VPS, CF proxy On.
5. Чеклист: 301 те же URL, sitemap, SSL, Метрика, формы, видео Range.
6. Не включать PHP/WP «для удобства».

VPS нужен, когда появятся кабинет, остатки, онлайн-оплата, приватные прайсы. До этого Pages выгоднее.
