# FW004tix — техническая спецификация Sirca

> Источник: `sources/sirca/specs/FW004tix.doc`

**Химический тип:** Водоразбавимое покрытие на акриловых смолах Назначение: Окраска дверей, стульев,

**Назначение:** Окраска дверей, стульев, плоских и фрезерованных изделий Способ нанесения: Распыление, в т

**Вес мокрого слоя:** ~115 г/м²

**Слоёв:** 2

## Описание

FW004tix прозрачный водоразбавимый однокомпонентный грунт для внутренней отделки. Предназначен для отделки дверей, плоских и фрезерованных изделий. Обладает хорошей наполяющей способностью и тиксотропностью, что делает его удобным для окраски стульев, балясин, решёток детских кроваток и т.п. На грунт также можно наносить полиуретановые лаки. При этом для увеличения физико-химической стойкости в грунт рекомендуется добавлять отвердитель CW3 (2%). Срок его действия в смеси при этом будет около 24 часов. По истечении этого срока нужно будет добавить отвердитель ещё раз.
