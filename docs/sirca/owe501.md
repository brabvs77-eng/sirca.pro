# OWE501 — техническая спецификация Sirca

> Источник: `sources/sirca/specs/OWE501.doc`

**Химический тип:** Водоразбавимое покрытие на акриловых смолах Степень блеска G, глосс 30 Назначени

**Назначение:** Окраска стабильных и полустабильных деревянных конструкций для экстерьера Способ нанесения: Кисть, распыление Физико-химические характеристики: Сухой остаток, %

**Блеск:** Окраска стабильных и полустаби

**Вес мокрого слоя:** ~175 г/м²

**Слоёв:** 2

## Описание

OWE501 однокомпонентный водоразбавимый cамогрунтующийся лак с медовым оттенком для экстерьера. Благодаря низкой вязкости подходит для нанесения кистью, при этом обладает хорошей тиксотропностью.
