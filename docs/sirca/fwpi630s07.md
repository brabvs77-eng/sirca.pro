# FWPI630s07 — техническая спецификация Sirca

> Источник: `sources/sirca/specs/FWPI630s07.doc`

**Химический тип:** Водоразбавимое покрытие на акриловых смолах Назначение: Окраска плоских и фрезер

**Назначение:** Окраска плоских и фрезерованных изделий Способ нанесения: Распыление, в т

**Вес мокрого слоя:** ~162 г/м²

**Слоёв:** 3

## Описание

FWPI630s07 белый водоразбавимый однокомпонентный грунт для внутренней отделки, специально разработанный для нанесения на подложки из MDF. Продукт обладает великолепной смачивающей способностью и быстротой сушки. Для нанесения на экзотические виды древесины, необходимо использовать надлежащие барьерные грунты.
