# FWE801 — техническая спецификация Sirca

> Источник: `sources/sirca/specs/FWE801.doc`

**Химический тип:** Водоразбавимое покрытие на акриловых смолах Назначение: Окраска окон, ставен, дв

**Назначение:** Окраска окон, ставен, дверей для экстерьера Способ нанесения: Струйный облив, окунание Физико-химические характеристики: Сухой остаток, %: 29 1 Плотность, г/см3

**Вес мокрого слоя:** ~90 г/м²

**Слоёв:** 1

## Описание

FWE801 однокомпонентный водоразбавимый прозрачный промежуточный грунт для окраски окон, ставен, входных дверей и других изделий для экстерьера. Наносится струйным обливом или окунанием, обеспечивает отличную смачиваемость пор и растекаемость без проблем с подтёками. Рекомендуется наносить после цветной пропитки (например, IMW4400 или IMW4800). Легко шлифуется. При необходимости может колероваться пастами PTW (до 3%) и разбавляться водой (до 10%). Если в процессе облива образуется много пены, в грунт можно добавить 0,05-0,3% пеногасителя CRW24. Внимание!
