# IMW4500 — техническая спецификация Sirca

> Источник: `sources/sirca/specs/IMW4500.doc`

**Химический тип:** Водоразбавимое покрытие на акриловых смолах Назначение: Окраска окон, дверей, са

**Назначение:** Окраска окон, дверей, садовой мебели и других конструкций для экстерьера Способ нанесения: Окунание, облив Рецептура смешивания (по весу): Готова к применению Ф

**Вес мокрого слоя:** ~75 г/м²

**Слоёв:** 2

## Описание

IMW4500 прозрачное пропитывающее средство для твердых и мягких пород дерева с хорошей растекаемостью и однородностью цвета, специально разработанное для применения на сложных поверхностях, которые обычно богаты танином и экстрактивными веществами. Может использоваться в чистом виде в качестве праймера
