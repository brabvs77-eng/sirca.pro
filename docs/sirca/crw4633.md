# CRW4633 — техническая спецификация Sirca

> Источник: `sources/sirca/specs/CRW4633.doc`

**Химический тип:** Водоразбавимое покрытие на акриловых смолах Назначение: В качестве нейтральной б

**Назначение:** В качестве нейтральной базы для получения цветного грунта Способ нанесения: Распыление Физико-химические характеристики: Сухой остаток, %: 64 1 Плотность, г/см3

**Вес мокрого слоя:** ~100 г/м²

**Слоёв:** 2

## Описание

CRW4633 нейтральный грунт-конвертер для создания цветного ВР грунта для интерьера. Колеруется пастами PNW (не более 6% по весу). Обладает высокой наполняющей способностью и укрывистостью, быстро сохнет, легко шлифуется. Может перекрываться акриловыми или водоразбавимыми лаками после сушки и шлифовки. Для очистки оборудования использовать воду или специальное чистящее средство CRW10. Внимание! При межслойном интервале более 2-х часов необходима шлифовка для обеспечения правильной адгезии.
