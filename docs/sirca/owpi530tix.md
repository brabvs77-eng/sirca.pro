# OWPI530TIX — техническая спецификация Sirca

> Источник: `sources/sirca/specs/OWPI530tix.doc`

**Химический тип:** Водоразбавимое пигментное покрытие на акриловых смолах Назначение: Окраска мебел

**Назначение:** Окраска мебельных фасадов, дверей, детской мебели, плоских и фрезерованных изделий Способ нанесения: Распыление, в т

**Вес мокрого слоя:** ~110 г/м²

**Слоёв:** 2

## Описание

OWPI530tix белая водоразбавимая тиксотропная эмаль для интерьера. Используется как самостоятельно, так и для получения пастельных цветов с помощью пигментных паст серии PNW (до 5%) по системе Colour Passion. Обладает отличной стойкостью к пожелтению, образует ровную и приятную на ощупь поверхность. Благодаря своим свойствам является реальной альтернативой стандартным продуктам для внутренней отделки на основе растворителя. Эмаль обладает хорошей стойкостью к царапинам. Тем
