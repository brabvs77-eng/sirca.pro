# OWPI930 — техническая спецификация Sirca

> Источник: `sources/sirca/specs/OWPI930.doc`

**Химический тип:** Водоразбавимое пигментное покрытие на акриловых смолах Назначение: Окраска мебел

**Назначение:** Окраска мебельных фасадов, дверей, детской мебели, плоских и фрезерованных изделий Способ нанесения: Распыление, в т

**Вес мокрого слоя:** ~110 г/м²

**Слоёв:** 2

## Описание

OWPI930 белая водоразбавимая эмаль для интерьера. Используется как самостоятельно, так и для получения пастельных цветов с помощью пигментных паст серии PNW (до 5%) по системе Colour Passion. Обладает высокой стойкостью к пожелтению, образует ровную и приятную на ощупь поверхность. Эмаль обладает достаточной стойкостью к царапинам. Тем
