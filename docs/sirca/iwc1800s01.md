# IWC1800s01 — техническая спецификация Sirca

> Источник: `sources/sirca/specs/IWC1800s01.doc`

**Химический тип:** Водоразбавимое покрытие на акриловых смолах Назначение: Окраска декинга, бортико

**Назначение:** Окраска декинга, бортиков бассейнов, садовой мебели, беседок и других полу- и нестабильных деревянных конструкций для экстерьера Способ нанесения: Кисть, валик,

**Вес мокрого слоя:** ~85 г/м²

**Слоёв:** 3

## Описание

При окраске новых изделий рекомендуемая влажность древесины должна быть 12-14%, максимальная 16-18%. Продукт наносится поверхность, предварительно отшлифованную абразивом P150-180.
