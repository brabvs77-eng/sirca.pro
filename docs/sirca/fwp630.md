# FWP630 — техническая спецификация Sirca

> Источник: `sources/sirca/specs/FWP630.doc`

**Химический тип:** Водоразбавимое покрытие на акриловых смолах Назначение: Окраска стабильных дерев

**Назначение:** Окраска стабильных деревянных конструкций для экстерьера Способ нанесения: Распыление, в т

**Вес мокрого слоя:** ~175 г/м²

**Слоёв:** 2

## Описание

FWP630 водоразбавимый белый грунт для окраски изделий для экстерьера с хорошей укрывистостью, эластичностью и изолирующими свойствами для отделки широколиственной и хвойной древесины. Тем
