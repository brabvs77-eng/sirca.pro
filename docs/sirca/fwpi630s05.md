# FWPI630S05 — техническая спецификация Sirca

> Источник: `sources/sirca/specs/FWPI630s05.doc`

**Химический тип:** Водоразбавимое покрытие на акриловых смолах Назначение: Окраска плоских и фрезер

**Назначение:** Окраска плоских и фрезерованных изделий Способ нанесения: Распыление, в т

**Вес мокрого слоя:** ~150 г/м²

**Слоёв:** 2

## Описание

FWPI630s05 белый водоразбавимый однокомпонентный грунт для внутренней отделки. Обладает высокой наполняющей и укрывной способностью, быстро сохнет, легко шлифуется. Подходит для отделки изделий из МДФ и дерева. Для нанесения на экзотические виды древесины необходимо предварительно использовать надлежащие барьерные грунты.
