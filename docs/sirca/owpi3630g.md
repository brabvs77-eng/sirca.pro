# OWPI3630G — техническая спецификация Sirca

> Источник: `sources/sirca/specs/OWPI3630g.doc`

**Химический тип:** Водоразбавимое покрытие на акриловых смолах Степень блеска G, глосс: 20, 30 Назн

**Назначение:** Окраска MDF и дерева для интерьера Способ нанесения: Распыление Физико-химические характеристики: Сухой остаток, %: 40 1 Плотность, г/см3: 1,250 0,010 Вязкость

**Блеск:** 20, 30 Назначение: Окраска MDF

**Вес мокрого слоя:** ~110 г/м²

**Слоёв:** 1

## Описание

OWPI3630G.. водоразбавимая белая матовая эмаль для интерьера. Обладает хорошей устойчивостью к царапинам, высокой укрывистостью, гладкостью на ощупь, отличной светостойкостью. Может колероваться пастами PNW (до 5%). Опционально, для увеличения физико-химической стойкости в смесь можно добавить 10% отвердителя CW5 (жизнеспособность смеси составит порядка 4-5 часов). Также можно добавить 2% кросслинкера ADTW422, при этом жизнеспособность смеси будет
