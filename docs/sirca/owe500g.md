# OWE500G — техническая спецификация Sirca

> Источник: `sources/sirca/specs/OWE500G.doc`

**Химический тип:** Водоразбавимое покрытие на акриловых смолах Степень блеска G, глосс: 30, 45, 60

**Назначение:** Окраска стабильных деревянных конструкций для экстерьера Способ нанесения: Распыление, в т

**Блеск:** 30, 45, 60 Назначение: Окраска

**Вес мокрого слоя:** ~275 г/м²

**Слоёв:** 3
