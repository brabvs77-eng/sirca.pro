# CR4072 — техническая спецификация Sirca

> Источник: `sources/sirca/specs/CR4072.doc`

**Химический тип:** Полиуретановый прозрачный ЛКМ Назначение: Окраска плоских и фрезерованных издели

**Назначение:** Окраска плоских и фрезерованных изделий Способ нанесения: Распыление Физико-химические характеристики: Сухой остаток, %: 54 1 Плотность, г/см3: 1,020 0,010 Вязк

**Вес мокрого слоя:** ~135 г/м²

**Слоёв:** 2

## Описание

CR4072 прозрачный высокоглянцевый полиуретановый конвертер, предназначенный для колеровки пастами серии FBU по системе Colour Passion с целью получения эмалей насыщенных цветов, а также для изменения блеска других конвертеров серии LPP2500.
