# FPP021 — техническая спецификация Sirca

> Источник: `sources/sirca/specs/FPP021.doc`

**Химический тип:** Полиуретановый пигментированный ЛКМ Назначение: Окраска плоских и фрезерованных

**Вес мокрого слоя:** ~200 г/м²
