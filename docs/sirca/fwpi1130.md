# FWPI1130 — техническая спецификация Sirca

> Источник: `sources/sirca/specs/FWPI1130.doc`

**Химический тип:** Водоразбавимое покрытие на акриловых смолах Назначение: Окраска плоских и фрезер

**Назначение:** Окраска плоских и фрезерованных изделий Способ нанесения: Распыление, в т

**Вес мокрого слоя:** ~140 г/м²

**Слоёв:** 2

## Описание

FWPI1130 белый водоразбавимый однокомпонентный грунт для окраски MDF. Специально разработан для использования на автоматических окрасочных линиях. Очень быстро сохнет, хорошо смачивает поверхность, легко шлифуется.
