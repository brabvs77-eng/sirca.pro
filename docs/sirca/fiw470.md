# FIW470 — техническая спецификация Sirca

> Источник: `sources/sirca/specs/FIW470.doc`

**Химический тип:** Водоразбавимое покрытие на акриловых смолах Назначение: Окраска стабильных дерев

**Назначение:** Окраска стабильных деревянных конструкций для экстерьера, в т

**Вес мокрого слоя:** ~105 г/м²

**Слоёв:** 1

## Описание

FIW470 двухкомпонентный водоразбавимый прозрачный барьерный грунт, специально разработанный для окраски изделий из твердолиственных пород, в т.ч. с высоким содержанием танинов (например, дуба), а также хвойных смолистых пород, в т.ч. лиственницы. Грунт наносится на изделия, предварительно обработанные цветными пропитками серий IMW4400 или IMW4800. Отвердитель следует добавлять тонкой струйкой при постоянном перемешивании, затем, спустя несколько минут, можно добавить воду.
