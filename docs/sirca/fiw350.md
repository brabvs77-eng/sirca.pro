# FIW350 — техническая спецификация Sirca

> Источник: `sources/sirca/specs/FIW350.doc`

**Химический тип:** Водоразбавимое покрытие на акриловых смолах Назначение: Окраска стабильных дерев

**Назначение:** Окраска стабильных деревянных конструкций для экстерьера из сосны, дуба, ореха

**Вес мокрого слоя:** ~110 г/м²

**Слоёв:** 1

## Описание

FIW350 однокомпонентный водоразбавимый тиксотропный прозрачный барьерный грунт, специально разработанный для окраски изделий из твердолиственных пород, в т.ч. с высоким содержанием танинов (например, дуба), а также хвойных пород с невысоким содержанием смолы (сосна, ель).
