# PUV2010 — техническая спецификация Sirca

> Источник: `sources/sirca/specs/PUV2010.doc`

**Химический тип:** Полиакриловый пигментированный ЛКМ УФ-отверждения Назначение: Отделка фасадов, д

**Назначение:** Отделка фасадов, дверей, и других плоских изделий Способ нанесения: Пневматическое распыление, AIRMIX и AIRLESS Физико-химические характеристики: Сухой остаток,

**Вес мокрого слоя:** ~135 г/м²

**Слоёв:** 2

## Описание

PUV2010 полиакриловый белый грунт для автоматических распылительных линий с УФ-сушкой. Предназначен для отделки фасадов и плоских панелей из МДФ. Имеет хорошую смачиваемость, укрывистость и растекаемость, легко шлифуется. Для улучшения адгезии к ламинированному МДФ рекомендуется добавлять 5% отвердителя CTN52, однако жизнеспособность при этом будет ограничена 24 часа.
