# FBU — техническая спецификация Sirca

> Источник: `sources/sirca/specs/FBU.doc`

**Химический тип:** Дисперсии пигментов в органическом связующем Назначение: Колеровка прозрачных и

**Назначение:** Колеровка прозрачных и пигментированных баз для получения цветных покрытий Срок и условия хранения: 12 месяцев в заводской таре

## Описание

FBU концентрированные универсальные органоразбавимые пигментные пасты, предназначенные для колеровки различных конвертеров (полиуретановых, акриловых, алкидных, нитроцеллюлозных, эпоксидных, виниловых, хлоркаучуковых, слюдисто содержащих) для получения цветных эмалей различных цветов по колорометрической системе COLOUR PASSION для интерьера и экстерьера, а также металликов. Для получения пастельных цветов добавляются в белые базы в соотношении
