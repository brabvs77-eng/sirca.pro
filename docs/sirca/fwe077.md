# FWE077 — техническая спецификация Sirca

> Источник: `sources/sirca/specs/FWE077.doc`

**Химический тип:** Водоразбавимое покрытие на акриловых смолах Назначение: Окраска стабильных дерев

**Назначение:** Окраска стабильных деревянных конструкций для экстерьера Способ нанесения: Распыление, в т

**Вес мокрого слоя:** ~175 г/м²

**Слоёв:** 2

## Описание

FWE077 однокомпонентный тиксотропный водоразбавимый прозрачный грунт для окраски изделий, эксплуатируемых вне помещений. Его уникальный состав гарантирует следующие преимущества: быстрая сушка, универсальность при использовании на Окуме и древесине с очень глубокими порами, которые он отлично смачивает, а также великолепная прозрачность (в сравнении с FWE700). Может быть использован в циклах со всеми продуктами для наружной отделки из ассортимента Sirca.
