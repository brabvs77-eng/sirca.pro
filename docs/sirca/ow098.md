# OW098 — техническая спецификация Sirca

> Источник: `sources/sirca/specs/OW098.doc`

**Химический тип:** Водоразбавимое покрытие на акриловых смолах Степень блеска (G), глосс: 30 Назнач

**Назначение:** Окраска фасадов, плоских и фрезерованных панелей, и мебели в сборе Способ нанесения: Распыление Физико-химические характеристики: Сухой остаток, %: 30 1 Плотнос

**Блеск:** 30 Назначение: Окраска фасадов

**Вес мокрого слоя:** ~100 г/м²

**Слоёв:** 3

## Описание

OW098 прозрачный самогрунтующийся водоразбавимый лак для внутренней отделки, обладающий хорошей твердостью, исключительной прозрачностью, хорошей химической стойкостью, хорошей скоростью сушки, замечательно подчеркивает поры и легко наносится. Может наноситься сам по себе, либо разведенный водой на 20%. При распылении можно использовать ручной краскораспылитель с соплом 1,8 - 2,0 мм и давлением 2-3 атм. Внимание! При межслойном интервале более 6 часов необходима шлифовка для обеспечения правильной адгезии.
