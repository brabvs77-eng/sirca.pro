# UVI3 — техническая спецификация Sirca

> Источник: `sources/sirca/specs/UVI3.doc`

**Химический тип:** Акриловый ЛКМ УФ-отверждения Назначение: Отделка плоских панелей Способ нанесени

**Назначение:** Отделка плоских панелей Способ нанесения: Порозаполняющие вальцы, реверс-вальцы Физико-химические характеристики: Сухой остаток, %: 98 1 Плотность, г/см3: 1,250

**Вес мокрого слоя:** ~40 г/м²

**Слоёв:** 1

## Описание

UVI3 акриловая прозрачная шпаклёвка УФ-отверждения для нанесения вальцами на плоские панели из массива или шпона дерева. Обладает отличной реакционной способностью и смачиваемостью. Шпаклёвка обеспечивает высокую адгезию к субстрату, однако, в отдельных случаях для увеличения адгезии можно добавить отвердитель CTN90 в количестве 4-6%.
