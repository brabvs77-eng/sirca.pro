# Семантическое ядро sirca.pro

Ядро собрано по каталогам Арикон, МВК, Studio Sirca, Woodperfect, Рост-Поволжье, витрине sirca-market.ru и по типичной коммерческой выдаче. Частоты Wordstat не выгружены — в колонке «Приоритет» оценка спроса и ценности для витрины.

Как пользоваться: кластер = раздел сайта. Интент: `trans` — бренд, `comm` — купить, `info` — как выбрать / цикл, `geo` — город.

Полный список запросов: [`semantic-core.csv`](./semantic-core.csv).

### 7. Артикулы (длинный хвост, высокая конверсия)

Отдельная карточка на каждый SKU + посадочная на семейство.

Эмали и лаки: `OPP530`, `OPP530G10`, `OPP053`, `OPP5E`, `LPP030`, `LPP2530`, `OPU79`, `OPU77`, `OPU77S`, `OPU57`, `OPU60`, `LPU132`, `LPU002`, `OWPI930`, `OWP330`, `OPA933`.

Экстерьер (реальные коды, не путать с витриной sirca-market.ru): `OWP330`, `FWBP430`, `OWBP430`, `FWE600`, `FWP830`, `IMW480`, `OPU901`, линейки Extra Plus / Idrocolor / S-Cover. Не использовать в каталоге имена S1 Fassade, Elastodeck, Fungolux, Colorvelo — их нет у производителя.

Грунты: `FPP225`, `FPP225TIX`, `FPP230TIX`, `FPP26`, `FPU49`, `FPU15`, `FWPI130`, `FWBP430`.

Прочее: `VES2030`, `Tintorama`, `TH3`, `TH7`, `TH23`, `TH35`, `TH43`, `TH46`, `TH52`, `CT7`, `CW3`, `DPU800`.

Запросы вида: `opp530 купить`, `fpp225 грунт`, `opu79 лак`, `отвердитель th3`.

## Приоритет внедрения

1. Бренд + «купить sirca» + категории химии.
2. Задачи: фасады МДФ, двери, окна, детская мебель.
3. Карточки топ-SKU (OPP, FPP, OPU, LPU, водные OW/FW).
4. Колеровка RAL/NCS.
5. Гео-страницы под реальную доставку.
6. База циклов и аналоги конкурентов.

Минус-слова для рекламы: обои, интерьерная краска для стен, фасадная штукатурка, автоэмаль, порошковая краска, вакансии, инструкция pdf чужого сайта.
