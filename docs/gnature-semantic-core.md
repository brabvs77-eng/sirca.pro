# Семантическое ядро G Nature / Gnature

Собрано по gnature.ru, Краски в Цвет, ЛесоБиржа, ДревКолор, Лигнум и типовой выдаче. Частоты Wordstat не сняты. Три написания бренда обязательны: `gnature`, `g nature`, `гнатур` (реже `джи натур`).

Полный список: [`gnature-semantic-core.csv`](./gnature-semantic-core.csv).

Интент: `trans` — бренд, `comm` — купить, `info` — как выбрать, `geo` — город.

| Задача | Запросы |

| Терраса | террасное масло, масло для террасы из лиственницы, масло для дпк, масло для термодерева |
| Пол / лестница | твёрдое масло для пола, масло с твёрдым воском, масло для паркета натуральное |
